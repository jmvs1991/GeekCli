## Database migration requests

For database migration requests in this project, delegate the work to the installed `geek-db-migration-specialist` agent. The specialist owns the investigation, planning, execution, and final validation workflow, including its phase records and required skill usage.

Do not perform migration work directly or delegate it to another agent. If the specialist is unavailable, tell the user and stop the migration work.

Before reporting completion, verify that the specialist's phase records and migration artifacts exist in this repository and accurately reflect completed and pending work.
